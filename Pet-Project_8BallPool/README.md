# QA Pet Project — 8 Ball Pool

This is a manual QA practice project focused on testing the 8 Ball Pool application.

## Project Documentation

The project includes the following documents and artifacts:

- **Pet Project Description** — project overview and description.
- **Test Plan** — testing scope, approach, and planned activities.
- **Mind Map** — visual representation of the testing structure.
- **Test Cases** — documented test scenarios and test steps.
- **Bug Reports** — defects identified and documented during testing.
